# 知识短片：先判断，再生成

## 这是什么

一套**判断规则**。它不渲染视频、不生成图片、不替你发。

它管三件事：

1. **选题值不值得做**（五问，答不满就不做）
2. **开头留不留得住人**（硬指标，能数）
3. **发出去之后数据说了什么**（回读，反过来改下一条）

## 这不是什么

- **不是一键出片工具。** 渲染要 HyperFrames + ffmpeg，这个插件不含。
- **不是爆款公式。** 下面的数字来自小样本实测，当方向用，不当定律。
- **不替你决定发不发。** 发不发是人的事。

---

## 一、选题卡：五问，答不满就别做

拿到一个选题，先答这五个。**任何一个答不出来，就不要开工。**

**① 开头第一句是什么？**
必须 ≤ 12 字，0.5 秒能读完，而且是个**反常**——数字、否定、或者把常识颠倒过来。

**② 主意象是什么？**
一个能贯穿全片的画面。**只能是一个。** 想到三个说明还没想清楚。

**③ 反转在哪？**
观众以为 A，其实 B。没有反转 = 没有重看的理由。

**④ 出处是什么？**
每条说法后面标一个：
- `已核实`（能指到原文/原始数据）
- `流行说法`（大家都这么说，但没找到源头）
- `我推测`（自己想的）

**⑤ 自评几分（10 分制）？**
低于 7 分不做。

> 这五问的价值不在答得漂亮，在于**答不出来的那一条**告诉你缺什么。

---

## 二、开头：第一屏决定一切

抖音在头几秒就决定把片子推给谁——2 秒和 5 秒的划走率会喂给后面所有的分发决策。**所以开头每秒钟值的情，比任何别的部分都多。**

下面这张对照，是十部爆款（每条取前 8.6 秒、六帧）和四条自己做的片子实测出来的：

| | 爆款（10 条） | 大多数人做的 |
|---|---|---|
| **第一屏** | 一个大主体居中，一眼认得出：一只眼睛占满画面、一个「我爱你」气泡、黑屋里一扇亮窗、一条红色跑道 | 一堆小窗口 / 三个神像叠在一起 / 一页外文手稿 |
| **文字可读** | **1.0 秒内**，常常第一帧就已经在了 | 1.3–1.6 秒之后 |
| **前 3 秒有没有变化** | **每次都有**，而且是那句话的承诺正在发生 | 有时 15 秒画面不动 |
| **画面和文字说的是不是一件事** | 是，静音也懂 | 有时不是 |
| **点题** | **7.5–8.6 秒**，一个大字 | 16–21 秒 |

### 六条（图文的写法）

**① 一个主体，大，居中，从第一张图就有。**
占画面至少三分之一，是最亮的东西，眼睛不用找就落上去。从日常里选：手机、窗、杯子、手、眼睛。**开阔远景、一堆小东西、一页外文、一个机械零件——全都不行。**

**② 第一张图里要有「正在发生的事」。**
视频里是计数器在跳、镜头在推、灯在灭。图文里是：**一个动作进行到一半**，不是摆好拍的一张静物。摆拍不叫变化。

**③ 不看字也要懂。**
静音看第一张图，能不能猜到这条讲什么。不能，就重画。

**④ 字 0.5 秒读完。**
第一句 ≤ 12 字，第一帧就该在。

**⑤ 最想看的那一屏，放在前三分之一。**
不要憋到最后。想让人看到的那一下，早点给。

**⑥ 每一屏都要有新信息。**
同一句话换三张图 = 三屏空转。

> 这些没有一条需要更大的预算。**都是选择。**

## 三、图文版的开头自检（四问）

做完第一屏，问四个问题，任何一个「否」就返工：

1. 只静音看这一屏，看得出这条讲什么吗？
2. 这一屏里有没有一个「正在发生」的动作？
3. 第一句能不能 0.5 秒读完？
4. 看完第一屏，想不想滑到第二屏？

## 四、审片：把感受变成计数

### 有视频时

- **空帧数**：画面超过 2 秒没变化的段，一条都不能有
- **稀薄帧**：只有标题没有新信息的段，尽量压到个位数
- **卡点比例**：画面变化落在重拍上的比例。参考爆款实测约 17%，随机是 7%。低于 10% 说明没对拍子

### 只有图文时（没有视频也能用）

- **段数**：一条图文超过 6 段，就是在跟人比耐心
- **每段第一句**是不是结论？如果是铺垫，把结论提到最前
- **最后一段**有没有给一个「所以你该做什么」

## 五、发布后回读：数据说的比感觉准

发出去 2 小时、24 小时各读一次，记四个数：

| 数 | 低的话说明什么 |
|---|---|
| **文案展开率 < 5%** | 开头没抓住。**不是内容不好，是没人往下看** |
| **划走率 > 50%** | 前三秒的问题 |
| **播放涨、点赞不涨** | 看完了但不认同，或者不够好 |
| **平均浏览图片数 < 2（共 4 张）** | 第一张不够勾人 |

**这三个数一起看：**

- 播放低 + 展开率高 → 内容对，分发不行，改标题/封面重发
- 播放高 + 展开率低 → 分发给到了，开头废了，改开头
- 都低 → 选题问题，别改文案了，换选题

---

## 六、用这条的数据改下一条

发完之后写一行：

```
第 N 条 | 播放 X | 展开率 Y% | 划走 Z% | 下一条要改：____
```

**只改一样。** 一次改三样，下次数据变了也不知道是哪一样起的作用。

---

## 已知限制

- 上面的阈值来自小样本实测（十几条作品），**当方向用，不当定律**。
- 平台的数据口径会变（展开率、完播率在不同版本里定义不同），用之前先确认。
- 这套规则只管「有没有人看完」，不管「看完之后有没有用」。后者只能靠人判断。
